# Kunyang Wang — Research Atlas

Official website source for GitHub Pages. Public-facing files only.

## Deploy

1. On GitHub, create a **public** repository named `kywang32.github.io` under the `kywang32` account.
2. Add **the contents of this folder**, not the containing folder and not the ZIP file itself, to the repository root.
3. In **Settings → Pages → Build and deployment**, select **Deploy from a branch**; branch `main`; folder `/(root)`; Save.
4. Visit `https://kywang32.github.io/` once the GitHub Pages workflow finishes.

All images in `photos/` are website derivatives; preserve the private master files offline. This repository contains photography by Kunyang Wang. No permission to redistribute or reuse photos is granted by publication of this repository.
